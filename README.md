<h1 align="center">DOGYSTILE</h1>
<p align="center">Лаунчер для Roblox: оверлей поверх игры, FastFlags, свои курсоры и шрифты, клипы одной кнопкой, итоги и каталог модов</p>

## Скачать

**[⬇ DOGYSTILE-Setup.exe](https://raw.githubusercontent.com/daniilakimkin1-oss/dogystile-download/main/DOGYSTILE-Setup.exe)**

1. Запустите `DOGYSTILE-Setup.exe`
2. Введите ключ, который получили при покупке
3. Установщик проверит ключ, скачает DOGYSTILE и установит его. Права администратора не нужны

Обновления приходят сами: DOGYSTILE предложит новую версию и поставит её поверх, настройки и ключ сохранятся.

## Требования

- Windows 10 (2004 и новее) или Windows 11
- Microsoft Edge WebView2 (в Windows 11 уже есть)

## Если Windows предупреждает

Установщик пока без цифровой подписи, поэтому SmartScreen может показать «Windows защитила ваш компьютер».
Нажмите **Подробнее → Выполнить в любом случае**.

## Безопасно ли это

DOGYSTILE ничего не внедряет в Roblox: он читает логи клиента, пишет FastFlags и моды в файлы клиента
и рисует оверлей отдельным окном поверх игры. Клипы снимаются средствами Windows.
